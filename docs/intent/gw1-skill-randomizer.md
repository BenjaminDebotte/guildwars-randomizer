# Confirmed Statement of Intent: Guild Wars 1 Skill Bar Randomizer

- **Outcome:** A rich Guild Wars 1 skill bar randomizer web app that generates single or multiple builds with valid in-game template codes (`[Skill Template Code]`) and attribute point distributions.
- **User:** GW1 players seeking build-crafting challenges, ironman runs, or variety with customizable constraints.
- **Why now:** Existing tools are either purely chaotic (spitting out unplayable junk) or lack granular game-logic controls (locking professions/elites, attribute schools, combo/sanity chains).
- **Success:** A player can configure rules (lock primary/secondary profession, lock/roll elite, filter campaigns, enforce mechanic/synergy sanity like combo chains vs. chaos mode), click roll, inspect visual 8-skill bars with tooltips and attributes, lock/reroll individual slots, and one-click copy template codes that import directly into Guild Wars 1.
- **Constraint:** Pure client-side static web app (runs completely in-browser, no backend server, fast, deployable anywhere like GitHub Pages, bundled offline skill database).
- **Out of scope:** Full 8-player hero party coordination/composition manager, account auth/cloud saved builds database, and in-game memory injection or direct client hooking.
